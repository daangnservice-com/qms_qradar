## 오늘 한 일 요약

무상태 앱에 **유일한 상태 저장 경로**로 사용량 트래킹을 붙임. 로그인 사용자가 **누가·어떤 화면을·언제** 접속했는지 라우트 변경마다 BigQuery(`striped-option-493506-a7.helpdesk_x.usage_events`)에 적재하고, **관리자(`karla@`)만** 사이드바 `/usage` 탭에서 집계를 본다. 옆 프로젝트 helpdesk-integrated-external의 검증된 트래킹 패턴을 이식해 새 데이터셋에 맞게 재구성. env·서비스계정 권한까지 **실제 BigQuery로 관통 검증** 완료.

---

## 결정 사항

- **목적**: 내부 도구 실사용 현황 파악 — 누가 얼마나, 어떤 탭을, 언제 쓰는지.
- **적재처**: 이미 쓰는 GCP 프로젝트 `striped-option-493506-a7`에 **`helpdesk_x` 데이터셋 신설**(사용자가 직접 생성), 테이블 `usage_events`. location `asia-northeast3`.
- **권한 모델**: 기존 앱은 관리자 개념이 없었음 → **관리자 1종(`ADMIN_EMAILS`) 신설**. 개인별 접속기록이라 사용량 탭·API 모두 `karla@`만. 콜/파손 탭은 기존대로 로그인=전체 사용.
- **인증**: 서비스계정 키(`GOOGLE_SERVICE_ACCOUNT_JSON`) 우선, 없으면 ADC. 키는 같은 프로젝트의 **다른 데이터셋에서 쓰던 SA(`google-group-checker@…`)를 재사용**.
- **트래킹 철학**: fire-and-forget. 미인증·env 미설정·적재 실패 어떤 경우에도 UX를 막지 않음(sendBeacon, 항상 204).

### ⚠️ 만료 미설정 (과거 사고 반영)
데이터셋 **기본 테이블 만료(defaultTableExpiration)를 일부러 설정하지 않음**. 예전 다른 헬프데스크 데이터셋이 60일 기본 만료로 테이블이 통째로 자동 삭제된 사고가 있어, 사용량 데이터는 무기한 보존하도록 명시적으로 만료 없이 생성.

## 구현 내역

- **`lib/adminEmails.ts`** — `ADMIN_EMAILS`(현재 `karla@`) + `isAdmin()`. 사이드바/API 공용 게이트.
- **`lib/bigquery.ts`** — `getBQ()`(SA키 or ADC), `ensureUsageTable()`(데이터셋·테이블 없으면 자동 생성, **만료 없음**), `insertUsageEvent()`(스트리밍 insert), `getUsageStats()`(일별·화면별·사용자별 5개 쿼리 병렬, Asia/Seoul 기준, `event='__verify'` 제외).
- **`components/UsageTracker.tsx`** — 루트 상주, `usePathname()` 변경마다 `sendBeacon('/api/track')`. `/api`·`/login`·정적자원 제외.
- **`POST /api/track`** — 세션 쿠키로 사용자 식별, 로그인 사용자만 적재, 항상 204.
- **`GET /api/stats/usage?days=N`** — 관리자 아니면 403. days clamp(1~365).
- **`/usage` 대시보드** (`app/(main)/usage/page.tsx`) — 총 조회수/접속자 수/기간 카드, 일별 접속 막대(경량 SVG), 화면별 접속 바, **사용자별 접속(펼치면 화면별·마지막 접속)**, 기간 7·30·90일 전환. 비관리자엔 "권한 없음" 표시.
- **연결부**: `app/layout.tsx`에 `<UsageTracker/>` 마운트, `Sidebar.tsx`에 관리자 전용 "사용량" 탭 추가(`adminOnly` 필터).
- **의존성**: `@google-cloud/bigquery` 추가.

## 검증 (실제 BigQuery 관통)

`.env.local`을 Next와 동일하게 로드하는 일회성 스크립트로 확인 후 스크립트 삭제:

- env 로드 정상 — 프로젝트 `striped-option-493506-a7`, 데이터셋 `helpdesk_x` 인식.
- SA `google-group-checker@…`(재사용 키)가 `helpdesk_x`에서 **테이블 생성·insert·query 권한 모두 정상**(조회용 SA라 쓰기가 막힐까 우려했으나 문제없음).
- `usage_events` 테이블 생성됨 — 스키마 `ts/user_email/path/event`, **만료 없음(무기한) 확인**.
- `tsc` 클린, `npm run build` 성공(`/usage`·`/api/track`·`/api/stats/usage` 라우트 정상).
- 검증행(`event='__verify'`) 1건은 대시보드 집계 쿼리에서 제외되도록 `getUsageStats` WHERE에 필터 추가.
