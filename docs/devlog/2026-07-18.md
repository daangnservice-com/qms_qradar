## 결정 사항

### 범위 / 방향
- **목표**: 상담원 콜 녹음(m4a)만 올리면 AI가 ① 품질 평가(태도/해결력/흐름) ② 통화 중 공백을 **초 단위**로 측정. 사람이 콜을 직접 듣지 않게 하는 것이 핵심.
- **공백의 의미**: 상담원이 어드민에서 검색하느라 대화가 비는 시간 → 그 길이를 재는 것이 목적.
- 평가 항목 3종: 응대 태도 / 문제 해결력 / 대화 흐름·공백 (각 1~5점).
- 공백 기준: 기본 3초, 화면 슬라이더로 1~10초 조절.

### 아키텍처 (이중 파이프라인)
- **공백**: ffmpeg `silencedetect`(신호 기반) → 초 단위 정확, 신뢰 소스.
- **평가/전사**: Gemini 2.5 Flash에 오디오 직접 전달. ffmpeg가 뽑은 공백 데이터를 프롬프트에 동봉해 근거 있는 코멘트 생성.
- 처리 로직을 `lib/*` 순수 모듈(HTTP 비의존)로 격리 → 2단계 Lambda 이식 대비.

### 단계 구분 (배포 전략 변경 이력)
- 명세서 v1: 로컬 동기 → v2: Vercel + S3 + Lambda 비동기 → **v3(확정): 1단계는 AWS 없이 Next.js 단독 동기 처리**.
- 이유: Vercel Hobby는 요청 본문 4.5MB·실행 60초 제한이 있어 30분 파일 처리가 불가. 하지만 **로컬 `next dev`는 그 제한이 없어** 지금 테스트엔 충분. AWS(S3+Lambda)는 인프라실 협의 후 2단계로.
- SSO(구글 @daangnservice.com)도 2단계로 보류.

## 구현 내역 (1단계)

서브에이전트 주도 개발(구현 → 리뷰 → 수정)로 진행. 각 Task TDD + 커밋.

- **스캐폴딩**: Next.js 15(App Router) + TypeScript + Tailwind v4(CSS-first) + Vitest. node v25에서 빌드 확인.
- **`lib/` 순수 모듈**
  - `types.ts` — 공용 타입
  - `format.ts` — `mm:ss` 포맷
  - `silence.ts` — ffmpeg 실행 + stderr 파서(fixture 단위테스트)
  - `audio.ts` — 임시파일 저장/정리
  - `gemini.ts` — 프롬프트 구성 + File API 업로드 + 구조화 JSON 파싱
  - `evaluate.ts` — 파이프라인 조립 + **AI 실패 시 공백 결과 유지** 폴백
- **API**: `POST /api/evaluate` — multipart 파싱, m4a·용량 검증, 임계값 클램프(1~10), `finally` 임시파일 정리.
- **UI**: 업로드 폼 + 결과 화면.

### 리뷰 후 하드닝
- Gemini 파일 폴링 무한루프 → 120초 타임아웃.
- 업로드한 Gemini 파일 사용 후 삭제.
- 빈 문자열 env 방어(`lib/env.ts`의 `numEnv`) — `MAX_UPLOAD_MB=""` 같은 실수 방지.

### 검증 (실측)
- 테스트 18/18 통과, `tsc --noEmit` 클린, `npm run build` 성공.
- ffmpeg로 합성한 15초 m4a(톤/무음/톤/무음/톤)로 end-to-end 관통:
  - 공백 **[5.0s, 4.0s]** 정확 검출, 공백비율 0.6.
  - 임계값 5초로 올리면 1건으로 필터링.
  - 비-m4a 업로드 → 400.
  - Gemini 키 없을 때 → 공백 결과 유지 + `evaluation.error` 표시(graceful).
  - 이후 실제 Gemini 키로 관통 시 평가/전사 정상 수신 확인.

## UI 리디자인

기존 화면이 조잡해서 사내 스위트 디자인 언어(참고 이미지)에 맞춰 갈아엎음.

- **레이아웃**: 좌측 사이드바(브랜드 + 네비, 네이비 활성 상태) + 메인(헤더/구분선 + 콘텐츠). 사이드바 접기 동작.
- **업로드**: 큰 드래그앤드롭 존(점선, 원형 업로드 아이콘) + `파일 선택` 버튼. 드래그 하이라이트, m4a 아니면 인라인 거부. 선택 시 파일 카드로 전환.
- **결과**: 점수 카드 3종(게이지) · 총평 · 공백 타임라인(스탯 타일 + 레드 트랙) · 접이식 전체 대화 스크립트.
- **색/타입**: 네이비 `#1e3a5f`(구조) + 오렌지 `#ff6f0f`(브랜드) + 레드 `#e5484d`(공백), 시스템 한글 산세리프.
- 다크모드 토글은 죽은 컨트롤 방지를 위해 미포함.
