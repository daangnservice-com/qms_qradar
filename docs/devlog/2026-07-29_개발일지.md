## 오늘 한 일 요약

페이팀 콜 분석(`/call-quality/pay`)에서 **필터 > 상담사 소속(팀)** 드롭다운을 열어 검색하면 계속 **"값이 없어요"** 만 뜬다는 제보. 원인은 데이터가 아니라 **필터 옵션 API의 권한 가드가 성장문화실 화이트리스트로만 걸려 있던 것**이었다. 가드를 조직 공통으로 완화하고, 겸사겸사 **실패를 조용히 삼키던 경로**(옵션 조회가 깨져도 화면상 "값이 없어요"와 구분 불가)를 걷어냈다.

## 원인 분석

- `app/api/call-quality/filter-options/route.ts`가 `canAccessCallQuality`(= `CALL_QUALITY_EMAILS`, **성장문화실** 목록)로 가드하고 있었다. 반면 샘플 목록 API(`samples/route.ts`)는 `canAccessOrg(org, …)`로 **조직별** 가드를 쓴다.
- 그 결과 **페이팀 전용 계정(taeo·heather)** 은 샘플 목록은 정상인데 **필터 옵션만 403** 을 받았다. (karla·amber.jeon은 양쪽 목록에 다 있어 재현되지 않는다 — 제보자 계정에 따라 증상이 갈리던 이유.)
- 프론트(`components/FilterPanel.tsx`)는 `r.ok ? … : null` + `.catch(() => {})` 로 실패를 **조용히 삼켜서**, `options`가 초기값 `{teamAgents: [], categories: []}` 그대로 남았다 → 팀·닉네임·카테고리 **드롭다운 3개가 전부** 빈 상태 → `MultiSelect`의 빈 상태 문구 **"값이 없어요"**.
- 같은 라우트의 catch 폴백도 문제였다. `200 + { teams: [], categories: [], adminNames: [] }` 를 돌려주는데, **클라이언트가 읽는 키는 `teamAgents`** 라 키 이름도 안 맞았다. 즉 **BigQuery 쿼리가 죽어도 화면 증상이 완전히 동일**해서 원인 분리가 불가능했다.

> 참고: 필터 옵션은 `data-proj-470202.ds_growth_culture.qradar_evaluation_cases`의 `case_content.$.operator_renewal_team_name` distinct다. 07-24에 정한 대로 **샘플 소스는 조직 공통**이므로, 페이팀 탭이라고 팀 목록이 달라지지 않는다 → 옵션 API를 조직별로 가드할 이유 자체가 없었다.

## 결정 사항

- **가드는 완화, 제거는 아님.** `canAccessCallQuality` → **`canAccessAnyCallQuality`**. 콜 분석 **어느 탭이든** 접근 권한이 있으면 옵션 조회를 허용한다. 옵션 자체가 조직 공통 데이터이고 팀명·닉네임·카테고리 목록뿐이라 조직별로 나눌 실익이 없다. 로그인·화이트리스트 자체는 그대로 유지(비허용 계정은 여전히 403).
- **대안이었던 "`?org=` 받아 `canAccessOrg`로 분기"는 안 씀.** 옵션이 공통인데 파라미터만 늘어나고, 페이팀 계정이 성장문화실 팀명을 못 보게 막는 것도 의미가 없다.
- **실패는 500으로 드러낸다.** `200 + 빈 옵션` 폴백을 없앴다. "옵션이 진짜 없음"과 "조회가 깨짐"이 화면에서 같아 보이면 안 된다.
- **프론트도 실패를 표시.** 배너로 알리되 **패널은 계속 열어둔다** — ID 입력·날짜·통화시간 필터는 옵션 없이도 쓸 수 있으므로 전체를 막지 않는다.

## 구현 내역 (전부 관리자 전용 기능)

- **`app/api/call-quality/filter-options/route.ts`** — 가드를 `canAccessAnyCallQuality`로 교체(왜 조직별이면 안 되는지 주석으로 남김). catch 폴백을 `200 + 빈 옵션` → **`500 + { error }`** 로 변경.
- **`components/FilterPanel.tsx`** — 옵션 fetch에서 `!r.ok`를 reject로 승격, `optionsError` 상태 추가. 실패 시 패널 상단에 안내 배너("팀·상담사·카테고리 목록을 불러오지 못했어요… ID 입력·날짜 필터는 그대로 쓸 수 있어요"). 성공하면 에러 상태 해제.
- **`app/api/call-quality/filter-options/route.test.ts`(신규)** — 401(세션 없음) / 403(비허용 계정) / **200(페이팀 전용 heather)** / 200(성장문화실 전용 laika) / **500(BigQuery 실패)**. 특히 heather 케이스가 이번 회귀를 직접 잠근다.
