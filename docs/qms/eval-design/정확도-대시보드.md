# 정확도 대시보드

레퍼런스 `data-screen-label="정확도 대시보드"`.  
**검수 현황**과 UI 레이아웃을 공유한다 (`components/eval-metrics/AccuracyMetricsShared.tsx`).

## UI

1. **상단 KPI** — Accuracy · Recall · Precision 가로 3카드. 각 카드에 0–100% 막대(색 임계 20 / 50 / 70 / 90).
2. **분류 지표** — FN → FP 순서(미탐·오탐), F1 · n.
3. **Confusion matrix** — 수기 검토필요＼AI 검토필요, 검토필요=positive.
4. **항목 섹션 (토글)**  
   - **주로 틀리는 항목** — 과검출(FP) top / 미검출(FN) top (겹치면 과검출만). TP/FP/FN 누적 막대.  
   - **항목별 AI–수기 감지 비교** — 차이 큰 순 / F1 높은 순, 카테고리 탭.
5. 평가표(프롬프트 버전) 필터 · Gate 90% 안내.
