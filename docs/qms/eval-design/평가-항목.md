# 평가 항목

레퍼런스 `data-screen-label="평가 항목 마스터"`.

## UI

3-pane: 카테고리(CS/직무) · 리스트 · 스티키 상세(기준, AI|수동, 버전).

서브타이틀: 현재는 **당근서비스워크 평가 어드민** 기준을 읽어 오기만 하며 이 화면에서 수정 불가. 향후 이 탭에서 카테고리·항목 추가를 지원할 예정. AI 프롬프트는 사이드바 「평가 항목 → AI 평가 항목」.

## helpdesk-x 매핑

- API: `GET /api/prompts/criteria?part=source`
- Store: `listSourceCriteria` → `vw_evaluation_criterions`
- 라우트: `/eval-design/items`

원본 뷰는 읽기 위주. 프롬프트 편집은 AI 평가 항목(`/eval-design/ai-items`, 메뉴 하위 뎁스).
