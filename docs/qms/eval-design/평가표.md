# 평가표

레퍼런스 `data-screen-label="평가표 관리"`.

## 개념 분리

| 용어 | 의미 |
|---|---|
| **평가표** | 다회 사용을 위해 만들어 둔 평가 기준·프롬프트 모음 **템플릿** |
| **평가 세션** | **1회 평가**를 위해 평가표 스냅샷(평가 기준, 평가 프롬프트)과 관련 정보를 고정한 실행 단위 |

레퍼런스의 「회차/스케줄」에 가깝지만, helpdesk-x에서는 **평가 세션**으로 부른다.  
현재 UI는 평가표(템플릿·버전) 관리가 중심이고, 세션 전용 화면은 후속이다. 운영(`production`) 지정 버전이 세션에 스냅샷으로 고정되는 전제.

## UI (리스트 ↔ 상세)

레퍼런스와 같이 **별도 뎁스**.

### 1) 버전 선택 (리스트)

- 평가표 / 평가 세션 안내 카피
- **새로 만들기**: 새 평가표 CTA + 정해진 템플릿 카드(이 템플릿으로 →)
- 테이블: 평가표 · 버전 · 항목수 · 상태 · 수정일 → 행 클릭 시 상세

### 2) 평가표 상세

- 목록으로 돌아가기
- 항목 바인딩 · 판정 파싱 · 오디오 · 버전 발행

## helpdesk-x 매핑

- API: `GET/POST /api/prompts`
- Store: `lib/promptStore.ts` (`savePromptVersion`, `setProductionVersion`)
- 라우트: `/eval-design/sheets`
- 템플릿 키: `call_eval_growth`, `call_eval_pay` (+ 빈 초안)

## 1차 생략

조직 매핑, 100점 배점, 완결·잠김 강제, 평가 세션(회차) 전용 화면·공지.
